# Samuel Batchelor - Project

## Project Description

### App Name: 
Rākau (Māori for "tree")

### Purpose:
Lets New Zealander's record, list and monitor notable, heritage or planted trees/shrubs within
their communities. It will serve as a useful tool for locals, councils, arborists and everyday Kiwis to contribute to a live record of NZ's tree and shrub population.

### Target Audience
- Local council parks/arborist staff who need to track protected/notable trees
- Community planting groups and conservation volunteers
- Home gardeners/lifestyle block owners logging their own plantings
- School/tertiary students (e.g. environmental science, horticulture) doing tree surveys

### Core Features
- Map view — Pins showing registered trees near the user, colour-coded by health status
- Add a tree/shrub record — Photo capture, species picker (native or exotic), notes (height,girth,status,planting date)
- Tree/shrub profile page — Photo gallery over time, growth log, health status, protection status
- Search & filter — by species, city, protection status, or "notable tree" registers, health status
- Personal tree/shrub dashboard — list of trees the user has logged onto the app.
