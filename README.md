# Samuel Batchelor - Project

## Project Description

### App Name: 
Rākau (Māori for "tree")

### Purpose:
Lets New Zealander's record, list and monitor notable, heritage or planted trees/shrubs within
their communities. It will serve as a useful tool for locals, councils, arborists and everyday Kiwis to contribute to a live record of NZ's tree and shrub population.

### Target Audience
- Local council parks/arborist staff who need to track protected/notable trees
- Community planting groups and conservation volunteers
- Home gardeners/lifestyle block owners logging their own plantings
- School/tertiary students (e.g. environmental science, horticulture) doing tree surveys

### Core Features
- Map view — Pins showing registered trees near the user, colour-coded by health status
- Add a tree/shrub record — Photo capture, species picker (native or exotic), notes (height,girth,status,planting date)
- Tree/shrub profile page — Photo gallery over time, growth log, health status, protection status
- Search & filter — by species, city, protection status, or "notable tree" registers, health status
- Personal tree/shrub dashboard — list of trees the user has logged onto the app.

## 1. App Concept

The Rākau app will be built to solve the issue of keeping a maintained record of the broad catalogue of New Zealand's exotic and native trees. The target audience will primarily be for anyone in New Zealand who wants to record individual trees. Users of this application will be people such as home gardeners, arborists, local/regional council members, conservation groups or just general citizen scientists/tree enthuasists. Additional users include people who work in plant nurseries, real estate developers and even school educators. The core functionality of this application will be for users to add and record trees they have identified, such as species, location and condition. Another key functionality is allowing users to browse the catalogue of recorded trees, so they can discover more about the trees within their local area or even across New Zealand. Another key functionality is for arborists and other professional users to maintain detailed records capturing their work on particular trees. Detailed records can consist of maintenance history of trees, or even just general reports of tree health status. One more key feature of this app would be to filter tree's by species, genus, height, girth, region and even significance status.

An additional feature maybe to have a graph for each recording tree showing their health status overtime, by adding follow-up observations to an existing record. Lastly another additional feature could be a version control backlog where users can see view a history profile for each recorded tree.

## 2. Backlog Selection and Requirement Analysis

### 10 User stories

1. As a home gardener, I want to add a tree I've identified with its species, location, and condition, so that I can keep a record of trees I've found.
2. As a citizen scientist, I want to browse the catalogue of recorded trees, so that I can discover interesting or notable trees in my local area.
3. As a tree enthusiast, I want to search for trees across New Zealand, so that I can learn about species outside my immediate region.
4. As a user, I want to have a page listing all of my recorded trees, so I can view what trees I have recorded.
5. As a user, I want to filter trees by height, girth, and region, so that I can narrow down results relevant to my search.
6. As a user, I want to filter trees by significance status, so that I can find notable or protected trees in an area.
7. As an arborist, I want to maintain detailed records for trees I manage, so that I have an accurate history of my professional work.
8. As an arborist, I want to log maintenance history for a specific tree, so that future work can be tracked over time.
9. As an arborist, I want to record a tree's health status in a report, so that I can monitor its condition across visits.
10. As a conservation group member, I want to view trees recorded in a specific region, so that I can monitor native or significant species in that area.
