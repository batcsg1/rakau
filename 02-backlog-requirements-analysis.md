### 2. Backlog Selection and Requirement Analysis

### 10 User stories

1. As a home gardener, I want to add a tree I've identified with its species, location, and condition, so that I can keep a record of trees I've found.
2. As a citizen scientist, I want to browse the catalogue of recorded trees, so that I can discover interesting or notable trees in my local area.
3. As a tree enthusiast, I want to search for trees across New Zealand, so that I can learn about species outside my immediate region.
4. As a user, I want to have a page listing all of my recorded trees, so I can view what trees I have recorded.
5. As a user, I want to filter trees by height, girth, and region, so that I can narrow down results relevant to my search.
6. As a user, I want to filter trees by significance status, so that I can find notable or protected trees in an area.
7. As an arborist, I want to maintain detailed records for trees I manage, so that I have an accurate history of my professional work.
8. As an arborist, I want to log maintenance history for a specific tree, so that future work can be tracked over time.
9. As an arborist, I want to record a tree's health status in a report, so that I can monitor its condition across visits.
10. As a conservation group member, I want to view trees recorded in a specific region, so that I can monitor native or significant species in that area.

### 10 User stories sorted by priority

1. As a home gardener, I want to add a tree I've identified with its species, location, and condition, so that I can keep a record of trees I've found.

It is important for basic functionality such as being able to add and view tree records as
this is the most basic functionality the app can provide.

2. As a user, I want to have a page listing all of my recorded trees, so I can view what trees I have recorded.

This will be a very helpful functionality as it easily allows a user to find the trees that have and maintain records for.

3. As a user, I want to filter trees by height, girth, and region, so that I can narrow down results relevant to my search.

Once basic adding and viewing functionality, have been added the next step is to filter
trees by particular fields to narrow down the user search results.

4. As a user, I want to filter trees by significance status, so that I can find notable or protected trees in an area.

Yet again, this is more filtering criteria for the user to utilize.

5. As an arborist, I want to maintain detailed records for trees I manage, so that I have an accurate history of my professional work.

This is especially important as this is one of the key basic requirements for arborists or any one who manages and maintains trees.

7. As an arborist, I want to record a tree's health status in a report, so that I can monitor its condition across visits.

Recording a tree's health status in a report is a requirement that extends from the above user story.

6. As an arborist, I want to log maintenance history for a specific tree, so that future work can be tracked over time.

This user story is more specific and extends from the two above, as this will allow arborists to have a good track record of the maintenance history for a specific tree.

8. As a citizen scientist, I want to browse the catalogue of recorded trees, so that I can discover interesting or notable trees in my local area.

Browsing a catalogue of recorded trees within a user's local area is a good starting places for wide search results for managed trees.

9. As a conservation group member, I want to view trees recorded in a specific region, so that I can monitor native or significant species in that area.

This is a further extension of being able to  view trees across a wide region, as this applies to any region or district in New Zealand, such as Otago or Canterbury

10. As a tree enthusiast, I want to search for trees across New Zealand, so that I can learn about species outside my immediate region.
